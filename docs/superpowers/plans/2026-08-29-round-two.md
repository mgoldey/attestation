- No caller-visible behaviour change except the ones the spec names: one tool fewer (`feed.personas` folded into `feed.persona_status`), two additive envelope keys (`checked`, `traced`), `scanned_at` on run detail, renamed domain functions (`feeds.*_source`, `Verdict.matched_*`). Every other envelope, message and order is byte-identical; every existing test stays green unless it exercises a renamed name (then it changes only at the call site).
- New tests use no database or model unless the spec marks the item I/O by nature (WB3, WB4, P3).
- Every new public def has a docstring; the docstring ratchet stays at 0; the complexity ratchet may only go down; no domain module imports `attestation.llm`; the MCP SQL ratchet (21) may only fall.
- Gates are centralised: implementers run their module tests plus `uv run --frozen ruff format <files> && uv run --frozen ruff check <files> && uv run --frozen ty check src/attestation`; the controller runs the full `pre-commit` once per wave.
